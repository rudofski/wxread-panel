wxread curl_bash 获取工具

Chrome 扩展最省心（含完整 HttpOnly 登录凭证）；F12 可靠备用

方式一：Chrome 扩展（推荐）✅ 含 HttpOnly 凭证

📥 下载扩展 ZIP（推荐） 📦 下载 CRX（Chromium/Edge）
下载上方 ZIP 包并解压到任意文件夹（CRX 仅 Chromium/Edge 用户可拖拽安装，Chrome 须用 ZIP 方式）
Chrome 地址栏输入 chrome://extensions 回车，打开右上角 开发者模式
点击 加载已解压的扩展程序，选择解压后的文件夹 → 工具栏出现 🎣 图标
打开 微信读书网页版 ↗ 扫码登录，进入任意一本书的阅读页
在阅读页翻一页 → 点击工具栏 🎣 图标 → 弹窗自动生成完整 curl_bash → 点 复制
粘贴到控制面板 → 配置参数 → 微信读书接口 → WXREAD_CURL_BASH → 保存

✅ 扩展可读取 HttpOnly cookie（wr_vid/wr_skey/wr_rt），生成的 curl 与 F12 完全一致，可直接刷时长。书签小工具因浏览器安全限制无法读取 HttpOnly 凭证，已不再提供。

方式二：F12 开发者工具（可靠备用）

在微信读书网页版登录并打开一本书
按 F12，切换到 Network 标签
过滤框输入 read，翻页触发一次阅读上报
右键 read 请求 → Copy → Copy as cURL (bash)
复制结果粘贴到控制面板 → 配置参数 → 微信读书接口 → 保存

✅ 同样包含完整登录凭证（含 HttpOnly cookie），刷时长必用

方式三：直接粘贴

复制后回到控制面板 → 配置参数 → 微信读书接口 → 粘贴到 WXREAD_CURL_BASH
