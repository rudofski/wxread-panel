wxread curl_bash 获取工具

三种方式任选其一

方式一：书签小工具（推荐）

打开 微信读书网页版，扫码登录
打开任意一本书，进入阅读页面
点击下方书签按钮，自动复制 curl_bash
拖我到书签栏

将此按钮拖到浏览器书签栏。在微信读书页面点击即获取 curl_bash

方式二：F12 开发者工具

在微信读书网页版登录并打开一本书
按 F12，切换到 Network 标签
过滤框输入 read，翻页
右键 read → Copy → Copy as cURL (bash)

方式三：直接粘贴

复制后回到控制面板 → 配置 → 粘贴到 WXREAD_CURL_BASH
